# LLM API pricing: official list prices and HopBase standard prices

**Data as of:** official list prices 2026-11-10 · HopBase standard prices effective 2026-10-31 · **License:** data CC BY 4.0, scripts MIT · [How to cite](CITATION.cff)

A machine-readable price sheet for 140+ text, image, video and speech models: the official list price of each model, and, for a set of popular models, the standard price on [HopBase](https://hop-base.com).

Maintained by HopBase, an AI gateway that serves these models through one base URL. Everything here is in USD.

- **Official list prices** come from the public endpoint `GET https://api.hop-base.com/api/v1/models/pricing` (no key needed). It returns the list price each model is billed against, per model maker.
- **HopBase standard prices** are what any registered user pays, with no contract, when the API key includes the listed key group. They are also published in [llms.txt](https://hop-base.com/llms.txt).
- Enterprise / volume pricing is quoted separately — contact sales@hop-base.com.

## Files

| File | What it holds |

## Use the data

The JSON and CSV files are plain files you can fetch directly:

```bash
curl -s https://raw.githubusercontent.com/HopBase-AI/llm-api-pricing/main/data/official-prices.json | jq '.models[] | select(.id == "claude-sonnet-5-5")'
```

```python
import json, urllib.request
url = "https://raw.githubusercontent.com/HopBase-AI/llm-api-pricing/main/data/official-prices.json"
models = json.load(urllib.request.urlopen(url))["models"]
```

To cite the dataset, use [`CITATION.cff`](CITATION.cff) (GitHub shows a "Cite this repository" button) and link back to https://hop-base.com.

## Reading the numbers

- Token prices are per 1M tokens. `cached_input` is the price of a cache read.
- A long-context tier applies to the whole request once input passes the threshold; the multipliers are relative to the base price.
- Video models bill per second or per 1M video tokens, and image models per image or per token, as the Unit column says.
- Peak / off-peak models list the peak rate. Off-peak hours follow the model maker's schedule.
- Three Doubao speech models in the catalog bill per character or per minute of audio and are left out of this sheet.
- Prices change. The dates in the tables say when each side was last read; the endpoint above and [hop-base.com/pricing](https://hop-base.com/pricing) are authoritative.
